# 股票技术指标与建仓判断设计

## 目标

为日线和分时筛选频道增加以下字段：

- MA20均线方向
- 平均波动幅度 ATR14
- 前10个交易日最低点
- 前10个交易日最高点
- 是否存在逆转趋势
- 是否适合建仓

所有历史窗口按交易日序列计算，不按自然日计算。所有技术指标都排除当前判断日；日线频道使用当日收盘价进行条件判断，分时频道使用实时价进行条件判断。

## 字段

| 页面字段 | API字段 | 类型与取值 |
| --- | --- | --- |
| MA20均线方向 | `ma20_direction` | `上升`、`下降`、`需人工判断` 或空值 |
| 平均波动幅度 ATR14 | `atr14` | 数值，展示时保留两位小数，或空值 |
| 前10个交易日最低点 | `previous_10d_low` | 数值或空值 |
| 前10个交易日最高点 | `previous_10d_high` | 数值或空值 |
| 是否存在逆转趋势 | `has_reversal_trend` | `是`、`否` 或空值 |
| 是否适合建仓 | `is_suitable_for_entry` | `是`、`否` 或空值 |

前端将上述字段的空值统一显示为 `-`。

## 统一的时间口径

设当前判断日为 `T`。无论日线还是分时频道，MA20、BOLL、ATR14和前10日高低点都只使用 `T` 之前的完整日 K，不包含 `T`。

日线频道：

- `T` 是最新已收盘日 K 的交易日。
- 当前价格取 `T` 日收盘价。
- `T` 日 K 只提供当前价格，不进入任何历史技术指标窗口。

分时频道：

- `T` 是当前市场交易日。
- 当前价格取长桥最新实时价。
- 每次查询均从长桥实时拉取最新价格与日 K。
- 如果日 K 接口返回 `T` 日尚未收盘的 K 线，必须排除该 K 线。
- 分时计算不读取日线指标表，也不落库。

## 指标公式

### MA20均线方向

`当前MA20` 使用 `T` 之前20个交易日的收盘价平均值。

`对比MA20` 是站在 `T` 之前第5个交易日，以相同规则取得的、该日之前20个交易日收盘价的平均值。

```text
MA20差值 = 当前MA20 - 对比MA20

MA20差值 > 0：上升
MA20差值 < 0：下降
MA20差值 = 0：需人工判断
```

两个窗口均排除各自的判断日。计算该指标至少需要 `T` 之前25个有效交易日的收盘价。

### BOLL

BOLL参数沿用现有配置：

```text
period = 20
std_multiplier = 2
```

BOLL使用 `T` 之前20个交易日的收盘价计算，不包含 `T`。日线和分时频道都用当前价格与该历史窗口计算出的上下轨进行比较。

新判断逻辑中的“下击BOLL”和“上穿BOLL”是价格位置判断，不要求发生跨轨穿越：

```text
下击BOLL：当前价格 <= BOLL下轨
上穿BOLL：当前价格 >= BOLL上轨
```

这与现有 `lower_breakdown` / `upper_breakout` 的穿越事件定义不同。现有信号字段的行为不在本次需求中修改。

### ATR14

每个交易日的标准 TR 定义为：

```text
TR = max(
  当日最高价 - 当日最低价,
  |当日最高价 - 前一交易日收盘价|,
  |当日最低价 - 前一交易日收盘价|
)
```

ATR14使用 `T` 之前14个交易日的TR平均值，不包含 `T`：

```text
ATR14 = (TR1 + TR2 + ... + TR14) / 14
```

为了计算窗口内第一天的TR，还需要该交易日前一日的收盘价。API保留数值精度，前端展示时保留两位小数。

### 前10个交易日高低点

```text
前10个交易日最低点 = min(T之前10个交易日的每日最低价)
前10个交易日最高点 = max(T之前10个交易日的每日最高价)
```

两个字段都返回单个数值，不返回价格列表。

## 逆转趋势

做多逆转：

```text
MA20方向 = 上升
且 当前价格 <= BOLL下轨
且 当前价格 < 前10日最低点 - 0.25 × ATR14
```

做空逆转：

```text
MA20方向 = 下降
且 当前价格 >= BOLL上轨
且 当前价格 > 前10日最高点 + 0.25 × ATR14
```

任一组条件全部成立时，`是否存在逆转趋势 = 是`；否则为 `否`。

## 是否适合建仓

适合做多建仓：

```text
MA20方向 = 上升
且 当前价格 <= BOLL下轨
且 是否存在逆转趋势 = 否
```

适合做空建仓：

```text
MA20方向 = 下降
且 当前价格 >= BOLL上轨
且 是否存在逆转趋势 = 否
```

任一组条件全部成立时，`是否适合建仓 = 是`；否则为 `否`。

当MA20方向为 `需人工判断` 时，两个判断字段均为 `否`。

## 数据流与组件

### 公共指标计算

在 `indicator_service` 中增加无数据库依赖的公共计算函数。函数接收按交易日升序排列的 OHLC 日 K 和当前价格，返回六个新增字段。日线同步和分时筛选调用相同的计算函数，避免两套公式产生偏差。

计算前必须：

- 按交易日期升序排列；
- 按交易日期去重；
- 排除当前判断日及之后的日 K；
- 验证所需 OHLC 字段完整。

### 日线频道

日线同步继续从长桥拉取行情，实际请求至少30根日 K。新增指标与现有日线指标一起写入 `stock_metrics_daily`。日线查询直接读取落库结果。

需要为 `stock_metrics_daily` 增加对应列，并在重复同步同一交易日时更新这些列。

### 分时频道

分时请求每次：

1. 从长桥拉取候选股票、实时价格和至少30根日 K；
2. 排除当前交易日的未收盘日 K；
3. 现场计算全部历史指标；
4. 结合实时价计算逆转趋势和是否适合建仓；
5. 将结果加入API响应，不写入数据库。

## 数据不足与异常处理

如果历史数据不足，或任一必需指标无法可靠计算：

- 六个新增字段全部返回空值；
- 前端六个字段全部显示 `-`；
- 不因单只股票的指标数据不足而中断整批筛选。

行情接口本身失败时沿用现有接口错误处理机制。单只股票存在重复日 K 时按交易日期去重后计算。

## API与界面

日线和分时结果都增加六个API字段。前端两个频道的结果表均增加对应列：

- MA20均线方向
- 平均波动幅度 ATR14
- 前10个交易日最低点
- 前10个交易日最高点
- 是否存在逆转趋势
- 是否适合建仓

ATR14展示两位小数。高低点沿用现有价格格式。布尔判断用中文 `是` / `否` 展示，空值显示 `-`。

本次只增加结果字段，不新增查询筛选条件，也不修改现有信号筛选的定义。

## 测试

指标单元测试覆盖：

- MA20上升、下降和差值为零；
- 两个MA20窗口相隔5个交易日且都排除各自判断日；
- 标准TR三种候选值分别成为最大值；
- ATR14排除判断日；
- 前10日高低点排除判断日；
- BOLL窗口排除判断日；
- 做多与做空逆转；
- 做多与做空适合建仓；
- 阈值相等时使用已确认的严格或非严格比较符；
- 历史数据不足时六个字段全部为空。

服务与API测试覆盖：

- 日线同步写入和重复同步更新新增字段；
- 日线API返回新增字段；
- 分时请求实时拉取行情并排除当天未收盘日 K；
- 分时API使用实时价计算判断字段；
- 分时流程不依赖日线指标落库结果；
- 前端类型、表头、格式化和空值展示。
